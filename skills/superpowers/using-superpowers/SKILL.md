# Using Superpowers

## Repository Routing

The default Industri Clicker router is `../../mobilegamedev-gram/SKILL.md`. Start routine repository work there.

This is a supporting skill. Use it only when the user explicitly requests Superpowers-style governance, asks to use Superpowers, or asks which Superpowers workflow applies. Do not invoke it merely because a task is broad, complex, or multi-step.

## When Invoked

1. Confirm the user wants the broader Superpowers workflow.
2. Identify the smallest relevant individual skill under `../`.
3. Read and follow that skill instead of applying a generic session-wide process.
4. Return to the repository router for project conventions, documentation paths, and verification expectations.

## Boundaries

- User and repository instructions take precedence.
- Do not require a skill check before clarification or routine repository exploration.
- Do not use this skill as a substitute for the local router or a task-specific local skill.
- Skip this skill when dispatched to complete a specific subtask.
